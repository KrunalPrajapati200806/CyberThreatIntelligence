# Cyber Threat Intelligence & Network Attack Mining

## Overview

A full-stack defensive cybersecurity analytics platform that
combines machine learning and data-mining techniques for
network attack detection, anomaly discovery, attack-pattern
mining, threat correlation and explainable threat intelligence.

## Core Technologies

- Python
- Scikit-learn
- Pandas
- MLxtend
- NetworkX
- SHAP
- FastAPI
- PostgreSQL
- React
- TypeScript
- Docker

## Core Modules

1. Network Traffic Analysis
2. Attack Classification
3. Clustering
4. Anomaly Detection
5. Association Rule Mining
6. Temporal Analysis
7. Network Graph Analysis
8. Threat Correlation
9. Risk Scoring
10. Explainable AI
11. Threat Intelligence Dashboard
